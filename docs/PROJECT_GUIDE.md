# 运行与使用说明

## 快速试玩

在线地址：<https://77-qiqi-playground.netlify.app/>。先用图画书点按听词，再体验听音任务和小游戏，最后到收藏小屋摆放伙伴。

当前在线版为 2026-10-30 的 V30。仓库包含 2026-10-31 的离线下载修复，尚未更新到线上。首次分享建议演示已经确认能完成的在线流程；不要宣传为已经通过真实 iPad 验收的离线应用。

## 开发与构建

技术栈为 React、TypeScript、Vite，存档使用 IndexedDB，离线能力由 Service Worker 提供。版本以 `package-lock.json` 为准。本次使用 Node.js 22.23.1。

```sh
npm ci
npm test
npm run build
npm run preview
```

`npm run build` 先做类型检查，再构建网页，最后验证图片与音频并生成离线清单和 Service Worker。`dist/` 是静态发布目录，不需要后端数据库。主项目工作目录外的旧网站配置不属于本项目，不能混用。

项目素材已随代码提供。`scripts/prepare-*-audio.py` 是制作阶段的辅助脚本，不是启动应用的必要步骤；它们可能需要独立 Python 环境、ffmpeg、语音模型及历史制作文件。不要为了试玩直接运行这些制作脚本。

## iPad 与离线

本机预览地址只能在运行服务的电脑打开。同 Wi-Fi 设备可通过显式绑定电脑的局域网地址试玩，例如 `npm run preview -- --host <电脑局域网IP>`。普通局域网 HTTP 不能据此验证 Service Worker 离线能力。

独立 iPad 使用需要可访问的 HTTPS 地址；从 Safari 添加到主屏幕后，应等待图片与声音完整下载，再实际断网、关闭并重新打开检查。下载期间可能受锁屏、后台挂起与储存空间影响。仓库包含本地 HTTPS 辅助脚本，但证书、私钥和信任设置均由各自设备单独管理，不随仓库分发。

## 存档与版本

家长口令 7707 只防误触。备份与恢复入口位于家长页。不同域名、端口、浏览器通常是不同存档；导出后再迁移，勿通过清除站点数据处理版本更新。

离线更新保留已校验文件，按文件补齐当前版本的缺失资源；没有实现大文件内部的字节断点续传或跨版本增量更新。更新完成后由家长保存并切换，不在游戏中主动刷新。

## 测试样例

`npm test` 使用 Node 内置测试运行器。部分测试会读取 `references/` 和 `output/` 中选定的内容清单、旧音频、旧源码与构造存档，不能只复制 `src/` 后要求完整测试通过。

本次整理保持游戏和学习逻辑不变。122 项测试通过；完整 iPad 实机触控、外放与离线验收不在本次结果之内。语音已生成和通过格式检查，也不等于每段发音已由人耳复核。

# 素材与声音说明

## 图片

`public/assets/` 保存项目制作过程中生成并使用的插画，包括概念图集、怪兽、场景与游戏角色；主要为 AI 生成图片，前端通过裁框和透明图层组合展示。README 中两张截图来自项目的隔离测试数据，不含真实儿童照片或真实使用存档。

本文件记录制作来源，不作素材权属、独占性或商用适用性的保证。项目中个别名称涉及常见角色叫法或现实车辆，应在对外复用时自行核对具体用途；不要把项目描述成相关品牌或角色权利人的官方产品。

## 音频

当前 895 段 MP3 包含英文 389 段与中文 506 段：

- 英文：Kokoro，`af_heart` 声音。
- 中文：Qwen3-TTS，`Uncle_Fu`，项目内制作风格标记 `D-playful`。
- 音频与文字、路径、哈希、生成器、制作批次等对应关系记录在 `public/audio/manifest.json`。

这是合成语音，不是孩子录音，也没有把孩子声音作为项目素材发布。模型权重与 Python 运行环境不包含在网页和仓库中。运行网页不需要在线语音服务。

制作过程使用的项目入口，供核对来源：

- [Kokoro](https://huggingface.co/hexgrad/Kokoro-82M)
- [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx)
- [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)
- [MLX Audio](https://github.com/Blaizzy/mlx-audio)

以上第三方项目的许可应以各自发布版本为准；不能用模型许可代替本项目全部图片、声音与代码的许可。项目尚未统一指定开源许可证。

## 使用边界

内容数量表示已配置的学习材料，不表示孩子已经掌握相应数量的词汇。任务记录区分接触、帮助后完成与当次正确，不是教学效果证明。音频的格式、哈希和响度检查也不能替代人耳审听，尤其是短词与中文声调。
